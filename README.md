# bilalsafdar4130.github.io

The Enigvra Studio website, served by GitHub Pages from `main`:
<https://bilalsafdar4130.github.io/>

| Path | What |
|---|---|
| `index.html` | Studio home: SparkLogic (on Google Play), the games, and a privacy section with a short summary per game linking to its full policy |
| `sparklogic/` | The SparkLogic landing page (formerly the site's home page) |
| `assets/` | Studio logo and favicon (from `bilalsafdar4130/privacy-policies`), game icons in `assets/games/` |
| `app-ads.txt` | AdMob's authorised-seller file. **Must stay at the site root**, unchanged, or ads stop serving |

The full privacy policies live in
[`bilalsafdar4130/privacy-policies`](https://github.com/bilalsafdar4130/privacy-policies)
(<https://bilalsafdar4130.github.io/privacy-policies/>); the summaries here must
agree with them. When a game goes live on Google Play, replace its
"Coming soon to Google Play" line in `index.html` with a link to
`https://play.google.com/store/apps/details?id=<package>`.
